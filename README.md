# ❤️ 델타룬 모작 : Turn-Based Battle Game

명령 선택형 턴제 전투와 실시간 탄막 회피를 결합한 Unity 2D 개인 프로젝트입니다.

3명의 파티원이 각자 `FIGHT`, `ACT`, `ITEM`, `MERCY`, `DEFENCE` 중 하나의 행동을 선택하고, 선택한 행동을 순차적으로 실행한 뒤 적의 탄막 패턴을 직접 회피하는 방식으로 전투가 진행됩니다.

플레이어와 적의 스탯 관리부터 행동 선택 UI, TP와 스킬, 아이템 사용, 타깃 선택, 타이밍 공격, 적 탄막 패턴, 피격 및 전투 종료까지 전투에 필요한 전체 시스템을 구현했습니다.

# 🎮 개발 내용 및 레포지토리 요약

## 🔄 1. Turn-Based Battle System

### 플레이어 턴과 적 턴 전환 시스템

`TrunManage`를 중심으로 플레이어 턴과 적 턴이 번갈아 실행되는 전투 흐름을 구현했습니다.

플레이어 턴에는 파티원별 행동 선택 UI가 활성화되고, 모든 파티원의 행동 선택과 공격 처리가 끝나면 적 턴으로 전환됩니다.

적 턴에는 플레이어 조작 오브젝트와 탄막 전투 영역을 활성화하고, 현재 페이즈에 맞는 적 공격 패턴을 실행합니다. 적 패턴이 종료되면 다시 플레이어 턴으로 복귀합니다.

```text
플레이어 행동 선택
        ↓
선택 결과 및 스킬 처리
        ↓
타이밍 공격 진행
        ↓
적 턴 시작
        ↓
탄막 패턴 회피
        ↓
적 패턴 종료
        ↓
다음 플레이어 턴
```

### 주요 기능

* 플레이어 턴과 적 턴 상태 관리
* 전투 UI와 회피용 플레이어 오브젝트 전환
* 적 패턴 시작 및 종료 처리
* 턴 전환 시 전투 영역 활성화
* 다음 플레이어 턴 데이터 초기화
* 파티원 전멸 및 적 처치에 따른 씬 전환

* 이름
* 현재 HP

## 🕹️ 3. Player Command Selection

### 파티원별 행동 선택 시스템

각 파티원이 자신의 턴에 실행할 행동을 선택할 수 있는 명령 선택 시스템을 구현했습니다.

좌우 방향키를 이용해 행동을 변경하고, 선택된 행동은 노란색으로 강조됩니다. `Z` 키로 행동을 확정하고 `X` 키로 이전 파티원의 선택 단계로 돌아갈 수 있습니다.

지원하는 행동은 다음과 같습니다.

```text
FIGHT   : 적에게 기본 공격
ACT     : 캐릭터별 고유 행동 및 스킬
ITEM    : 보유 아이템 사용
MERCY   : 조건을 충족한 적 살려주기
DEFENCE : 방어하고 TP 획득
```

한 명의 파티원이 행동을 확정하면 다음 파티원의 선택으로 이동하며, 세 명 모두 행동을 결정하면 선택 결과를 순차적으로 실행합니다.

### 추가 처리

* 파티원별 독립적인 행동 정보 저장
* 선택 행동과 세부 행동 분리 관리
* 이전 행동 선택 단계 복귀
* 행동 취소 시 사용한 TP 복원
* 행동 불능 파티원 자동 건너뛰기
* 다인 스킬 사용 시 다른 파티원의 행동 생략
* 턴 시작 시 선택 상태와 UI 초기화

## ✨ 4. ACT & Skill System

### 캐릭터별 스킬 시스템

각 파티원이 보유한 고유 스킬 목록을 동적으로 생성하는 ACT 시스템을 구현했습니다.

스킬 데이터에는 이름, 설명, 필요 TP, 타깃 종류와 다른 파티원의 참여 여부가 포함됩니다.

스킬 선택 화면에서는 현재 보유 TP와 스킬의 요구 TP를 비교하여 사용 가능 여부를 표시합니다. TP가 부족한 스킬은 선택할 수 없으며, 스킬을 확정하면 필요한 TP를 차감합니다.

### 스킬 데이터

* 스킬 이름
* 스킬 설명
* 필요 TP
* 적 또는 아군 타깃 여부
* 두 번째 파티원 참여 여부
* 세 번째 파티원 참여 여부

### 주요 기능

* 캐릭터별 스킬 목록 생성
* 스킬명과 설명 출력
* 요구 TP 실시간 표시
* TP 부족 시 사용 차단
* 스킬에 필요한 파티원 아이콘 표시
* 적·아군 타깃 선택 연결
* 스킬 선택 취소 및 UI 정리
* 다인 스킬 선택 시 참여 파티원 행동 생략

## ⚡ 5. TP System

### 전투 자원 관리

스킬과 방어 행동에서 사용하는 TP 전투 자원을 구현했습니다.

TP는 0부터 100까지 관리되며, UI Slider와 TextMeshPro 텍스트를 통해 현재 수치를 표시합니다.

방어 행동을 선택하면 TP를 획득하고, 스킬을 사용하면 설정된 수치만큼 TP를 소모합니다.

```text
방어 행동 선택 → TP 20 획득
스킬 사용       → 스킬 요구량만큼 TP 차감
행동 취소       → 차감하거나 획득한 TP 복원
```

TP가 100을 초과하지 않도록 최대치를 제한하고, 변경 사항이 발생할 때마다 UI를 갱신하도록 구성했습니다.

## 🎒 6. Item System

### 아이템 선택 및 소비 관리

아이템 이름, 설명, 회복량과 사용 가능 여부를 데이터로 관리하는 아이템 시스템을 구현했습니다.

아이템 화면을 열면 현재 보유한 아이템 목록이 동적으로 생성되며, 선택 위치에 맞춰 아이템 설명이 갱신됩니다.

아이템을 선택하면 회복 대상 선택 화면으로 이동하고, 선택한 아이템의 이름과 회복량을 해당 파티원의 행동 데이터에 저장합니다.

### 주요 기능

* 아이템 목록 동적 생성
* 아이템 이름과 설명 표시
* 아이템별 회복량 설정
* 회복 대상 선택
* 선택한 아이템 임시 제거
* 파티원 행동 순서에 따른 아이템 상태 보관
* 이전 선택 단계 복귀 시 아이템 목록 복원
* 최종 선택 결과에 따른 아이템 데이터 갱신

아이템 선택 과정에서 이전 단계로 돌아갈 수 있기 때문에 원본 목록, 현재 목록과 임시 목록을 분리하여 관리하도록 구성했습니다.

## 🎯 7. Target Selection System

### 적 및 아군 타깃 선택

행동 종류에 따라 적 또는 아군을 선택할 수 있는 타깃 선택 시스템을 구현했습니다.

적 타깃을 선택할 때는 적의 이름과 현재 체력을 표시하고, 회복 행동에서는 파티원의 이름과 현재 체력을 표시합니다.

타깃 UI는 현재 전투 데이터를 기반으로 실행 시점에 동적으로 생성됩니다.

### 주요 기능

* 적 타깃 목록 생성
* 아군 타깃 목록 생성
* 타깃 이름 표시
* 타깃별 HP Slider 표시
* 상하 방향키를 이용한 타깃 변경
* 선택한 타깃 인덱스 저장
* 이전 스킬·아이템 화면으로 복귀
* 선택 종료 후 생성된 UI 오브젝트 제거

특정 다인 스킬을 선택한 경우 필요한 파티원의 행동을 자동으로 생략하도록 행동 선택 시스템과 연결했습니다.

## ⚔️ 8. Timing Attack System

### 타이밍 기반 기본 공격

`FIGHT` 행동을 선택한 파티원은 별도의 타이밍 공격 UI를 진행합니다.

공격 노트는 오른쪽에서 왼쪽으로 이동하며, 플레이어가 노트가 판정 위치에 도달했을 때 `Z` 키를 입력하면 공격이 처리됩니다.

공격에 참여하는 파티원마다 독립적인 공격 레인이 활성화됩니다.

```text
FIGHT 선택 파티원 확인
        ↓
파티원별 공격 노트 생성
        ↓
노트가 판정 영역으로 이동
        ↓
Z 키 입력
        ↓
현재 노트 판정
        ↓
적에게 데미지 적용
```

### 노트 생성 및 순서 보정

각 파티원의 공격 노트에는 무작위 지연값이 적용됩니다.

동일한 지연값을 가진 노트는 같은 공격 순서로 그룹화하며, 서로 다른 지연값은 오름차순으로 다시 정렬하여 `NoteList`를 재설정합니다.

이를 통해 무작위 위치로 생성된 노트를 실제 공격 순서에 맞게 처리할 수 있도록 구현했습니다.

### 동시 공격 처리

여러 파티원의 노트가 같은 타이밍에 배치된 경우 해당 공격을 동시 공격으로 처리합니다.

한 파티원이 타이밍 입력에 성공하면 동일한 순서에 존재하는 다른 파티원의 노트를 함께 탐색하고, 공격 참여 여부를 저장한 뒤 각 파티원의 데미지를 적용합니다.

### 데미지 계산

```text
최종 데미지 = 플레이어 공격력 - 적 방어력
```

계산 결과가 0 이하인 경우에도 최소 1의 데미지가 적용됩니다.

## 💥 9. Damage & Combat Result System

### 데미지, 회복 및 행동 결과 처리

파티원이 선택한 행동을 순서대로 실행하고, 결과를 전투 설명 텍스트와 데미지 UI에 반영하는 시스템을 구현했습니다.

행동 종류에 따라 다음 처리가 실행됩니다.

* 기본 공격 데미지
* 스킬 데미지
* 아이템 회복
* 회복 스킬
* MERCY 조건 확인
* 방어 행동
* 행동 불능 상태 건너뛰기

행동 결과는 파티원 순서에 맞춰 텍스트로 출력되며, 플레이어가 `Z` 키를 입력하면 다음 결과로 넘어갑니다.

### 전투 종료

* 적의 HP가 0 이하가 되면 클리어 씬으로 이동
* 모든 파티원의 HP가 0 이하가 되면 게임오버 씬으로 이동

## ❤️ 10. Player HP & Knockout System

### 파티 체력 및 행동 불능 관리

각 파티원의 이름과 HP를 Slider에 연결하는 체력 UI를 구현했습니다.

체력 정보가 변경되면 최대 체력과 현재 체력을 갱신하며, HP가 0 이하인 파티원은 행동 불능 상태로 처리합니다.

행동 불능 상태의 파티원은 다음 플레이어 턴에서 자동으로 행동 선택 대상에서 제외됩니다.

### 주요 기능

* 파티원 이름 표시
* 최대 HP 및 현재 HP 표시
* HP Slider 갱신
* 행동 불능 여부 실시간 확인
* 행동 불능 파티원 선택 건너뛰기
* 전체 파티원 전멸 검사
* 잘못된 데이터 인덱스 오류 출력

## 🛡️ 11. Player Dodge System

### 적 턴 실시간 이동 및 피격

적 턴에는 플레이어가 방향키를 이용해 회피용 캐릭터를 조작할 수 있습니다.

`Rigidbody2D`의 Velocity를 사용해 수평·수직 이동을 처리하며, `X` 키를 누르고 있는 동안 이동 속도를 낮춰 정밀하게 탄막을 피할 수 있도록 구현했습니다.

### 조작 방식

```text
방향키 : 상하좌우 이동
X 키   : 저속 이동
```

적의 탄환에 충돌하면 살아 있는 파티원 중 한 명이 무작위로 피해를 받습니다.

연속 충돌로 피해가 중복되는 문제를 방지하기 위해 피격 후 0.5초 동안 무적 상태를 적용했습니다.

일반 탄환은 플레이어와 충돌하면 제거되며, 유지형 공격 오브젝트는 충돌 후에도 남아 있을 수 있도록 태그를 구분했습니다.

## 👾 12. Enemy Turn Pattern Controller

### 적 공격 페이즈 관리

`EnemyCreateHit`에서 적 턴에 실행할 공격 패턴을 통합 관리합니다.

처음 여섯 번의 적 턴에는 정해진 순서대로 서로 다른 공격이 실행됩니다.

```text
1턴 : 부채꼴 탄환
2턴 : 원형 순차 발사
3턴 : 대포 투사체
4턴 : 회전 톱니 패턴
5턴 : 플레이어 추적 낙하 탄환
6턴 : 회전목마 패턴
```

여섯 개의 패턴을 모두 실행한 이후에는 일부 기존 패턴 중 하나를 무작위로 선택하여 반복합니다.

각 패턴은 Coroutine으로 실행되며, 패턴이 끝나면 공통 `EndTurn` 처리를 통해 플레이어 턴으로 전환됩니다.

## 🔺 13. Spread Bullet Pattern

### 부채꼴 탄환 공격

적 위치에서 여덟 개의 탄환을 부채꼴 형태로 발사하는 패턴입니다.

총 네 번의 탄환 묶음을 생성하며, 발사할 때마다 각도에 좌우 오프셋을 번갈아 적용합니다.

이를 통해 같은 위치에서 발사되더라도 탄환 사이의 빈 공간이 매번 달라지도록 구성했습니다.

### 패턴 구성

* 한 번에 8개 탄환 생성
* 총 4회 반복
* 108도 범위에 탄환 분배
* 발사마다 각도 오프셋 반전
* 탄환 묶음 사이 대기 시간 적용

---

## 🔄 14. Radial Sequential Bullet Pattern

### 원형 순차 발사 패턴

적을 중심으로 여덟 개의 탄환을 360도 방향에 배치한 뒤, 일정한 간격으로 순차 발사하는 패턴입니다.

탄환을 처음 생성했을 때는 제자리에서 대기하도록 설정하고, 개별 탄환의 `RotateMove`를 호출하여 이동을 시작합니다.

각 반복마다 발사 순서를 정방향과 역방향으로 변경하여 공격 흐름에 변화를 주었습니다.

```text
원형 탄환 생성
      ↓
탄환을 바깥쪽으로 위치 보정
      ↓
순차적으로 이동 활성화
      ↓
다음 반복에서는 반대 순서로 발사
```

## 🎯 15. Cannon Attack Pattern

### 플레이어 조준 대포 공격

화면 위쪽의 무작위 좌우 위치에서 대포를 생성하는 패턴입니다.

대포는 아래쪽으로 이동하다가 무작위 높이에 도달하면 플레이어 위치를 바라보는 투사체를 생성하고 제거됩니다.

생성된 대포알은 생성 순간의 플레이어 위치를 향해 이동하며, 자식 오브젝트를 회전시켜 시각적인 회전 효과를 표현합니다.

### 주요 기능

* 좌우 무작위 위치에서 대포 생성
* 무작위 높이까지 대포 낙하
* 플레이어 방향 조준
* 대포알 이동 속도 무작위 설정
* 대포알 회전 속도 무작위 설정
* 파괴 영역 충돌 시 오브젝트 제거

---

## 🪚 16. Saw & Track Pattern

### 회전 톱니 공격

트랙 형태의 공격 오브젝트를 생성하고 일정 시간 동안 회전시키는 패턴을 구현했습니다.

톱니 오브젝트에는 시작 위치와 중앙 위치를 오가는 왕복 이동 Coroutine도 구현되어 있습니다.

`Vector2.Lerp`를 이용하여 두 위치 사이를 일정 시간 동안 부드럽게 이동하고, 파괴 영역과 충돌하면 오브젝트를 제거합니다.

---

## 🌧️ 17. Falling Bullet Pattern

### 플레이어 위치 기반 낙하 탄환

현재 플레이어의 X축 위치를 중심으로 상단에서 탄환을 생성하는 패턴입니다.

총 40개의 탄환을 생성하며, 플레이어 위치 주변에 무작위 오프셋을 적용합니다. 탄환 생성 간격도 일정 범위 내에서 무작위로 설정하여 불규칙한 낙하 공격을 구성했습니다.

### 주요 기능

* 플레이어 X축 위치 추적
* 좌우 무작위 오프셋
* 상단 무작위 높이
* 총 40개 탄환 생성
* 탄환별 생성 간격 무작위 적용
* 생성 후 낙하 속도 설정

## 🎠 18. Merry-Go-Round Pattern

### 전후 레이어 회전목마 패턴

여러 개의 회전목마 오브젝트가 화면의 앞쪽과 뒤쪽 레이어를 이동하는 패턴입니다.

앞쪽 오브젝트는 밝게 표시되고 높은 Sorting Order와 활성화된 Collider를 사용합니다. 뒤쪽 오브젝트는 어둡게 표시되며 낮은 Sorting Order를 사용하고 Collider가 비활성화됩니다.

오브젝트가 좌우 끝 지점에 도달하면 진행 방향과 앞뒤 상태를 전환합니다.

### 주요 기능

* 7개의 회전목마 오브젝트 생성
* 앞쪽 그룹과 뒤쪽 그룹 분리
* 앞뒤 상태에 따른 Sprite 색상 변경
* Sorting Order 변경
* Collider 활성화 및 비활성화
* 좌우 끝 지점에서 방향 반전
* 이동 방향에 따른 상하 움직임
* 일정 시간마다 수직 이동 방향 변경
* 패턴 종료 후 생성 오브젝트 일괄 제거

## 🔫 19. Common Bullet System

### 공통 탄환 이동 및 제거

일반 탄환은 자신의 `transform.up` 방향으로 이동합니다.

원형 순차 공격에 사용되는 탄환은 처음에는 이동을 멈춘 상태로 생성한 뒤 위치를 보정하고, 공격 순서가 되면 일반 이동 상태로 전환합니다.

화면 바깥으로 이동하거나 `DestroyZone`과 충돌한 탄환은 자동으로 제거됩니다.

## 🏠 24. Lobby & Scene Flow

### 로비 및 게임 진행 씬 관리

로비 화면에서 게임 시작 버튼을 누르면 전투 씬으로 이동하도록 구현했습니다.

로비에서는 화면 해상도를 `675 × 508`로 설정하고, 부제목 UI를 지속적으로 회전시키는 간단한 연출을 적용했습니다.

프로젝트는 다음 네 개의 씬으로 구성되어 있습니다.

```text
Lobby
  ↓
SampleScene
  ├── GameOver
  └── Clear
```

### 씬 구성

* `Lobby.unity` : 시작 화면
* `SampleScene.unity` : 메인 전투
* `GameOver.unity` : 파티 전멸
* `Clear.unity` : 적 처치 완료
